# Entorno Exclusivo de Depuracion en Windows (Rama: WindowsTest)

Esta carpeta esta destinada a albergar scripts, utilidades de prueba, harnesses de ejecucion y pruebas de depuracion en Windows sin alterar la estructura principal de produccion de la app movil.

## Contenido y Proposito
- Pruebas de integracion y depuracion sobre plataforma Windows.
- Scripts de validacion directa contra los datasets locales (`dataset/`).
- Registro y persistencia del progreso de depuracion en la rama `WindowsTest`.
